# Sample data (for demonstration only)
- `SAMPLE_iris_classification.csv` - Fisher's Iris (scikit-learn bundled), target `species`.
- `SAMPLE_diabetes_regression.csv` - scikit-learn bundled diabetes dataset, target `target`.
- `SAMPLE_synthetic_churn_classification.csv` - **synthetic** data generated with a fixed seed (numpy), with injected missing values and categorical columns; target `churned`.
These are not production data. The app labels them "Sample data".
